# sebrogala.dev — exact 1.2A handoff

This package is derived directly from the **selected 1.2A Balanced mark** in the original brand board.

## Important
This is **not a manual redraw** and not a newly generated interpretation.

The silhouette was isolated from the selected board, its two connected white components were traced, and only raster stair-stepping was simplified. The resulting vector keeps the selected mark's:
- exact relative top/bottom geometry,
- relative spacing,
- angles,
- asymmetry,
- overall proportions.

The source crop used for verification is included at:
`reference/selected-1.2A-source-crop.png`
